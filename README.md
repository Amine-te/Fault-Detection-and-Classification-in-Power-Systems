# PowerAI: Power System Fault Detection and Classification

PowerAI is an advanced AI solution for detecting and classifying faults in electrical power systems using machine learning and deep learning techniques. This project addresses the critical need for intelligent fault detection in modern power systems, leveraging cutting-edge artificial intelligence to provide real-time, accurate, and interpretable fault detection capabilities.

## Key Features

- **Real-time Anomaly Detection:** Advanced autoencoder neural networks continuously monitor power system signals
- **Intelligent Fault Classification:** Automatic categorization of detected anomalies into specific fault types
- **Interactive Monitoring Dashboard:** Comprehensive web-based interface for real-time visualization
- **Feature Importance Analysis:** Advanced analytics to understand fault signatures
- **Multi-signal Processing:** Comprehensive analysis of voltage and current measurements across multiple phases
